# 📌 TJDesktopTimetable —— 把课表钉在你桌面上

**一句话**：这是一个 Windows / Linux 桌面小挂件，把你这学期的课表变成一块半透明的彩色格子，**常驻在桌面右下角**。不用打开教务、不用掏手机、不用翻截图，抬头就是「今天第几周、今天几节课、下一节在哪间教室」。

---

## 🧩 它长什么样、能干什么

- **一格一门课**：同一天同一节次撞在一起的课会自动并排显示；单双周、1-8 周这类短课会打条纹标记，不会假装整学期都上。
- **周次视图（默认「只看本周」）**：平时只画这一周的课，一屏就是真实的一周；想通览整学期就切成「全部周次」。放假 / 开学日未知时自动退回显示全部，**挂件不会变成一块空白**。
- **顶部一行信息**：学期名 · 第 N 周 · 今日 N 节（这个数字永远按当前教学周算）。
- **一条时间线**：按节次走，课间停在上一节末尾，不糊弄。
- **贴桌面层**：跟桌面图标待在一起，按 Win+D「显示桌面」它还在；不会挡你干活。
- **四种材质**：Mica / Mica Alt / Acrylic / 轻薄亚克力，深浅主题都跟系统走。
- **能拖能缩**：位置尺寸记在本地，下次打开还是老地方。
- **托盘 + 右键菜单**：显示/隐藏、重新载入、恢复默认位置、显示周末开关、周次视图、退出。
- **开机自启**（可选，一个开关）、**发现新版本会提示**（点一下跳下载页，不偷偷装）。
- **离线优先**：唯一联网行为是启动后查一次新版本（可关）。课表数据只存在你自己电脑上。

## 🏫 支持哪些学校

- **同济大学**（1 系统个人课表）
- **上海交通大学**（「学在交大」）
- 架构上是「一个学校 = 一个适配器文件」，所以**其他学校也能加** —— 想加的话把你们学校课表页的接口告诉群里就行。

## ⬇️ 怎么装（Windows）

1. 打开项目主页 → 右侧 **Releases** → 下载最新那个 `TJDesktopTimetable-…-setup.exe`。
2. 双击一路下一步（会弹一次 UAC 管理员确认，因为装在 Program Files）。
3. 装完启动，**第一次会显示一张虚构的示例课表**，并自动打开设置的「导入」页 —— 让你自己选学校、自己登录。看到示例课表不要慌，那不是你的真实数据。

## 🔑 怎么导入自己的课表

两条路，选一条就行（推荐第一条）：

1. **应用里直接登录**：设置 →「导入」页 → 选学校 → 「登录并获取课表」。登录窗口是应用自己的浏览器，跟你平时在网页上登录一模一样（含短信验证），登录完课表自动就位。
2. **粘一条浏览器请求**：在浏览器里打开课表页 → F12 → 网络 → 刷新 → 找到课表那个请求 → 右键「复制为 cURL」→ 粘进「导入」页。**注意：这个请求里带着你的登录 Cookie，只粘贴到本应用里，别发到群里！**

## 🐧 Linux

有 Avalonia 版（X11 / XWayland）。数据目录和 Windows 版同构，`settings.json` / `timetable.json` 可以互拷。安装方式和限制见项目 README。

## ❓ 常见问题

- **课表不对 / 是空的**：① 确认导入的是**个人课表**（不是专业培养计划那种一节课挂一堆教学班的页面）；② 顶部显示「假期」= 现在不在教学周内（寒暑假属正常）；③ 在「关于」页点「重新载入课表」试一次；④ 还不行就把「导入」页显示的**探测行文字**截图发群里。
- **周次对不上（第几周错了）**：多半是开学日没取到。把导入页那一行诊断发群里，加一个学校的开学日就能修。
- **会上传我的课表 / 学号吗**：不会。应用没有服务器，课表只写在你自己的 `%APPDATA%\TJDesktopTimetable\`；请求日志里也不打印 Cookie 内容。
- **为什么默认只显示一周**：课表本来就该是「这一周」。想回到整学期视图：设置「外观」页 → 周次视图 → 全部周次（挂件右上角 ⋯ 菜单、托盘菜单里也能切）。
- **其他学校能用吗**：暂时不行，但加适配器的成本不高 —— 群里说一声，最好附上你们课表接口的响应样例。
