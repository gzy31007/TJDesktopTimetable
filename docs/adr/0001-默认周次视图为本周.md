# 周次视图默认「只看本周」，假期静默退回全部

课表挂件原先一屏画出整个学期（单双周交替的两条安排并排/相邻都在），用户要的是"课表就应该是这一周"。因此新增周次视图（全部 / 本周 / 单周 / 双周）并**把默认值定为「本周」** —— 老用户升级后观感会变（色块变少、并排变整宽），这是刻意的。

配套的反直觉选择：当"当前教学周"不存在时（开学前、学期结束后、或内置学期表未命中导致开学日未知），**不显示空网格，而是静默退回显示全部周次**（header 保持「假期」）。显眼路径是显示空挂件，但那会让"开学日未知"的用户（未来学期导入）看到一块空白桌面，且无从判断是数据没导进来还是这一周没课。代价是"过滤开关打开了、看起来却没生效"，因此设置页的说明文字静态写明"开学日未知时显示全部周次"。
