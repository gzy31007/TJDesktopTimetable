# 周次视图用字符串枚举落盘

`settings.json` 里现有的枚举（`ThemeMode` / `MaterialMode`）都是**数字**落盘（序列化选项里没有 `JsonStringEnumConverter`）。新增的周次视图刻意偏离这套口径：在 `WeekView` 类型上单独挂 `[JsonConverter(typeof(JsonStringEnumConverter))]`，落成 `"weekView": "current"`。

理由：设置文件变得可读可手改；将来增删取值不依赖枚举顺序（数字落盘一旦重排就会把用户已保存的设置解释成另一个值）。代价有两个：这是本项目第一处"枚举不落数字"的地方，下一个工程师很可能想"统一"回去；以及枚举字符串写错会让 STJ 解析失败，整份设置回落默认值 —— 这与既有的"坏 JSON 就回落默认"是同一条兜底路径，不新增复杂度。不给 `ThemeMode` 一起改成字符串，是为了不破坏已发布版本写出的设置文件。
