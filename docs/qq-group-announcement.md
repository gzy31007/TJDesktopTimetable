TJDesktopTimetable 课表挂件

把课表变成半透明彩色格子钉在你桌面上：一眼看清今天第几周、几节课、下一节在哪间教室。同济、上海交大可用，Windows / Linux 都有。

亮点：默认只显示本周，放假自动退回整学期；单双周和短课有标记；同格撞课自动并排，不互相盖住；按 Win+D 显示桌面后它还在；可拖可缩、开机自启；离线优先，只在启动时查一次新版本。

安装：GitHub 搜 gzy31007/TJDesktopTimetable，进 Releases 下 setup.exe，一路下一步。第一次启动显示的是虚构的示例课表，别慌；按提示选学校、登录，就导入好你自己的课表了。

群里会发新版本通知，也能报 Bug、提需求、催加学校；有问题请带上版本号和截图。
