TJDesktopTimetable 课表挂件 · 把课表钉在桌面上

适合所有人的桌面课表挂件（同济 / 上海交大）：半透明彩色格子常驻桌面，一眼看清今天第几周、几节课、下一节在哪间教室。Windows / Linux 都有。

业务一句话：把一学期课表拆成「导入 → 周次 → 布局 → 呈现 → 贴桌面」五步 —— 从教务取到你自己的课表，算清今天属于第几周，把撞在同一格的课并排摆开，按深浅主题染色，最后像桌面图标一样钉住（按 Win+D 也还在）。

亮点：默认只显示本周，放假自动退回整学期；单双周和短课有标记；可拖可缩、开机自启；离线优先，只在启动时查一次新版本。

安装：GitHub 搜 gzy31007/TJDesktopTimetable，进 Releases 下 setup.exe，一路下一步。第一次启动显示的是虚构示例课表（不是你的数据），按提示选学校、登录即可导入。
