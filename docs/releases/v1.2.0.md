# TJDesktopTimetable v1.2.0

**Linux 版首次发布**（Avalonia 壳），Windows 版同轮做视觉与材质收口：时间列收窄、色块提亮、名称按宽度截断、时间线按节次分段。

## 下载

- `TJDesktopTimetable-v1.2.0-win-x64.zip` · Windows（自包含：**不需要**预装 .NET 或 Windows App Runtime）
  → 解压到任意**本地磁盘**目录 → 双击 `Tjt.App.exe`
- `TJDesktopTimetable-v1.2.0-linux-x64.tar.gz` · Linux（自包含单文件：**不需要**预装 .NET）
  → `tar -xzf ...` → 运行解压目录里的 `Tjt.Linux`

## 新增

**Linux 版（`dotnet/Tjt.Linux/`，Avalonia 12）**

- 与 Windows 版**同一套核心**：TjtCore 解析 / Tjt.Widget 算几何与染色，Linux 壳只做"必须在 Linux 桌面上跑"的事
  （Avalonia 窗口、X11 层级、文件与网络 IO），渲染层是 WinUI 版的同构移植（照数字摆控件）。
- **贴桌面层** = X11 `_NET_WM_WINDOW_TYPE_DOCK` + `_NET_WM_STATE_BELOW`；KDE Plasma 实测「显示桌面」后挂件仍可见
  （只做 keep-below 会被一起藏掉，DOCK 类型是必须的）。
- **拖动 / 缩放**走 Avalonia 原生循环（`BeginMoveDrag` / `BeginResizeDrag`），热区几何与最小尺寸仍由
  `Tjt.Widget` 的 `CursorZones` / `ResizePolicy` 纯函数决定 —— Windows 那套 16ms 光标轮询是 WinUI 指针捕获缺陷
  逼出来的补丁，Linux 不需要。
- 导入：**粘贴一条浏览器请求 / JSON**（内置登录窗口是 WebView2 专属，Linux 无对应，功能等价）。
- 数据目录 `~/.config/TJDesktopTimetable/`，`settings.json` / `timetable.json` / `credentials.json` 与 Windows 版同构可互拷。
- 运行依赖：X11 或 XWayland；Avalonia X11 后端需要 **`libICE` / `libSM`**（缺了启动即崩）；中文课表需要 CJK 字体。

**「轻薄亚克力」材质档**

- 材质下拉现在是四档：Mica / Mica 备选 / Acrylic / **轻薄亚克力**；Acrylic 两档回到
  `DesktopAcrylicController` 实现（此前一轮误判"Acrylic 不可用"已纠正）。
- 深色档参数按 DeskBox 的机制重设（低 tint + 高亮度）：Mica `tint 0.25 / luminosity 0.86`、
  MicaAlt `0.55 / 0.53`、Acrylic `0.45 / 0.60`、轻薄亚克力 `0.23 / 0.36`（浅色各低一档）。
- 材质切换仍是**运行时即时生效、不重建窗口**（复用同一个 `SystemBackdropConfiguration`）。

## 修复

- **时间线不再"课间继续爬"**：原先整张网格线性插值，12:30 落在第 4 行内、13:00 已经爬进第 5 行（13:30 才上课）。
  现在按节次分段 —— 节内按该节起止插值，**课间钉在刚上完那一节末尾**，早于首节 / 晚于末节不画。
  真机实测（1100×760）：09:50 → 172.7 DIP、12:30 → 276.7、13:40 → 288.0、20:56 不画线。
- **网格画布贴顶**：固定尺寸画布在大槽位里被默认居中（实测下移 57 DIP，表头与顶部条之间凭空多出一大块），
  现在显式 `VerticalAlignment = Top`，6 DIP 呼吸位恢复本意。
- **挂件未激活时不再发灰**：材质主题此前没显式设过 `Theme`，跟随系统深浅色 —— 系统深色时即便选浅色也是深底，
  半透明色块叠上去反而更暗。现在主题随应用设置走（装饰主题 / 材质主题 / 重排三件一起更新），
  并去掉按 `Activated` 改 `IsInputActive` 的老逻辑（挂件几乎不激活 → 长期"非激活"灰底）。

## 变更

- **视觉收口**（改的是 `Tjt.Widget`，两端一起变）：
  - 时间列 74 → **64 DIP**，左侧时间标签改**居中**（不再出现"文字与左边距随字号变小而变大"）；
  - 深色色块提亮：填充 30% → **38%**、悬停 40% → 48%、描边 45% → **52%**（浅色档未动）；
  - 名称截断**按实际宽度**逐字估宽（西文 0.55 em、中文 1.0 em，省略号先占位）：窄块从"2 字 + …"变"1 字 + …"，不再依赖 `TextTrimming` 兜底。
- `AGENTS.md` 项目说明压缩 39%（66 KB → 40 KB），事实与结论一条未丢，新增「Linux 线」章节。

## 质量

- 平台无关单测 **237** 项全绿（`TjtCore` + `Tjt.Widget`，Linux / CI 上就能跑）。
- CI 三个解决方案分别门禁：`TjtTimetable.slnx`（ubuntu + windows 双平台跑测试）、
  `TjtTimetable.Windows.slnx`（Windows 编译门禁）、`TjtTimetable.Linux.slnx`（ubuntu 编译 + 自包含发布）。
- 自动化验收脚本（`.tools/`，纯 ASCII）：`verify-import.ps1`、`verify-login.ps1`、`verify-auto-login.ps1`、
  `verify-icon.ps1`、`verify-weekend.ps1`、`verify-resize.ps1`、`verify-move.ps1`、`verify-converge.ps1`、
  `verify-topology.ps1`、`live-check.ps1`。
- 实测（黄金 fixture，14 门 / 19 条）：显示周末 `days=7 blocks=19 colW=173`；隐藏周末 `days=5 blocks=17 colW=242`；
  冒烟 `[smoke] ok blocks=19 canvas=977x600`。

## 已知限制

- **Linux 版是 X11 / XWayland only**：Avalonia 稳定线没有原生 Wayland 后端；KWin（KDE）对 XWayland 窗口的
  keep-below / DOCK 支持完整，其他 WM 行为未验证。Linux 版暂无托盘与独立设置窗口（开关都在挂件 `⋯` 菜单里），
  KWin 重启后贴桌面层状态会丢（重开一次应用即可）。
- Windows 版：内置登录需要 WebView2 运行时（Win11 与较新的 Win10 已自带）；研究生页 `findSchoolTimetab2`
  分支按前端源码实现、**未真机实测**；内置学期表只覆盖已知学期（`122` / `124`），更远的学期顶部不显示"现在第几周"。
- **周次过滤（只看单周 / 双周）仍未实现**（「显示周末」自 v1.1.0 起可用）；Acrylic 需要透明窗口，观感可能弱于 Mica。
- 产物只有 x64（Windows 10 2004+ / linux-x64）。
