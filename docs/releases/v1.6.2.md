# TJDesktopTimetable v1.6.2

修复 Windows 更新下载入口不出现的问题，并补上持续运行期间的版本检查。这是 v1.6.1 的补丁更新。

## 修复内容

- 发现新版后，在挂件顶部显示“下载新版”。检查结果返回、跳过版本后，挂件和已打开的设置窗口立即更新，不必重开窗口。
- 启动约 12 秒后检查最新正式版，之后每轮完成后间隔 6 小时重查。仍可关闭自动检查，关于页保留手动检查与“跳过此版本”，下载按钮移至挂件顶部。
- 下载沿用现有 gh-proxy.org 镜像直链，优先 Windows 安装包，其次 zip；无匹配资产时退回发布页。没有新增静默下载或自动安装。
- 手动与自动检查不重叠，退出时取消等待和网络请求；检查失败保留已有结果，请求期间跳过的版本不会被旧响应重新提示。
- 不改变已有课表与配置格式。Linux 本次仅随统一版本重新构建，不新增 Windows 的更新提示功能。

## 下载与升级

- `TJDesktopTimetable-v1.6.2-setup.exe`：Windows 安装包，推荐使用，可覆盖安装旧版并保留课表和设置。
- `TJDesktopTimetable-v1.6.2-win-x64.zip`：Windows 绿色版，退出旧程序后解压到本地目录运行。
- `TJDesktopTimetable-v1.6.2-linux-x64.tar.gz`：Linux 自包含版，需要 X11 / XWayland、libICE / libSM 和中文字体。

Windows 包自包含，不需预装 .NET 或 Windows App Runtime。安装包未签名，SmartScreen 可能提示未知发布者。若旧版受本次问题影响而看不到下载按钮，请直接从本发布页下载安装包。

## 验证与边界

修复已通过 559 项核心测试、Windows 编译与固定日期冒烟。隔离真实 WinUI 控件检查覆盖窄/宽窗口、反复检查、跳过、安装包/zip 链接选择及网络失败；用户已人工操作下载入口与跳过。现有镜像的真实浏览器下载与 SHA256 也已核验，使用的是当时最新的 v1.6.1 安装包，不冒充 v1.6.2 安装验证。

周期由受控时间测试覆盖，未真实连续等待 6 小时。未新增安装器运行、系统通知呈现/点击、混合 DPI 或 Linux 桌面运行时验收。
