# TJDesktopTimetable v1.5.0

**课表现在默认只画「这一周」** —— 一屏就是真实的一周，不再把整学期（含单双周交替的副本）全铺在桌面上。
附带新增：设置「关于」页的 **QQ 群二维码**（扫码入群反馈问题 / 接新版本通知）。

> ⚠️ **升级后观感会变**：老用户第一次打开会发现色块变少、并排的课变整宽。这是刻意的（见下），
> 想回到"整学期一起看"：设置「外观」页 → 周次视图 → **全部周次**（挂件右上角 `⋯` 菜单、托盘菜单里也能切）。

## 下载

- `TJDesktopTimetable-v1.5.0-setup.exe` · **Windows 安装包（推荐）**
  → 双击安装 → 装到 `Program Files`；向导可勾选开始菜单 / 桌面快捷方式 / 开机自启 / 装完启动
- `TJDesktopTimetable-v1.5.0-win-x64.zip` · Windows 绿色版（自包含，**不需要**预装 .NET 或 Windows App Runtime）
  → 解压到任意**本地磁盘**目录 → 双击 `Tjt.App.exe`
- `TJDesktopTimetable-v1.5.0-linux-x64.tar.gz` · Linux（自包含单文件）
  → `tar -xzf ...` → 运行解压目录里的 `Tjt.Linux`

**没有代码签名**：Windows 首次运行/安装时 SmartScreen 会提示"未知发布者"，点「更多信息 → 仍要运行」即可。

## 新增：周次视图

- **四态互斥**：全部周次 / **只看本周**（默认）/ 只看单周 / 只看双周。刻意不做正交组合
  （"本周 ∩ 单周"能推出空课表这种自相矛盾的状态）。
- **「本周」= 今天所在的教学周**：第 1 周从开学日那一周的周一起算；所以切到"本周"就是"我现在该上什么"。
- **假期静默退回全部周次**：开学前、学期结束后、或学期表未命中导致开学日未知时，
  **不显示空网格**，而是照旧画全部周次（顶部仍显示「假期」）——挂件永远不会变成一块空白。
- **只决定画哪些课**：冲突判定、今日高亮、「今日 N 节」都不受视图影响；被本周丢掉的时段
  计入"被过滤隐藏"的统计（与单双周同一口径）。
- **三处入口同一份设置**：设置「外观」页的下拉框、挂件右上角 `⋯` 菜单的「周次视图」子菜单、
  托盘右键菜单的同名子菜单；托盘用普通勾选（不设菜单位图的托盘菜单画不出单选圆点）。
- **顺带修正一个既有错误**：顶部「今日 N 节」原先数的是"画出来的色块"，会把别的周的课算进今天
  （例如双周课在第 1 周根本不上，却被算进"今日"）。现在它**永远按当前教学周**算；假期退回"今天有几条安排"。
- **诊断开关**：`--week-view all|current|odd|even` 与 `--today YYYY-MM-DD`（后者是"今日"的唯一真源：
  今日高亮 / 当前教学周 / 今日节数都看它），都只影响本次运行、不落盘。
- **落盘格式**：`settings.json` 里写成字符串（`"WeekView": "Current"`），可读可手改；
  未知取值 → 整份设置回落默认，不会因为一个字段写错就起不来。

## 新增：设置「关于」页 QQ 群二维码

- 「关于」页底部多了一块 **QQ 群**：二维码 + 群号（可选中复制）+ 兜底提示（扫不动就直接搜群号）。
- 二维码是运行时从安装目录的 `Assets/qq-group.png` 加载的，缺文件只会留一行日志、界面不崩。

## 保持 v1.4.2 的行为

- 查到新版本会弹 Windows 系统通知，点它直达设置「关于」页；同一个版本每次运行只提醒一次。
- 版本查询先直连 `api.github.com`（6 秒），直连不通再经 `gh-proxy.org` 镜像重试；「下载」按钮给的链接
  也指向镜像，国内点开就能下。不想联网：设置「常规」页关掉「检查新版本」即可。

## 已知限制

- **升级后默认观感变化见文首**：这是产品决策（课表就应该是"这一周"），不是 bug。
- 周次视图只影响"画哪些课"：不会改变冲突判定，也不会把并排的课拆开。
- 托盘子菜单里的勾选位置只能人工看（原生弹出菜单无法用脚本断言）。
- 没有代码签名；`gh-proxy.org` 是第三方镜像（会 301 到 `gh-proxy.com`），只用于版本查询与下载，
  **不上传任何本机数据**。
