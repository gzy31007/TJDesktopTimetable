# TJDesktopTimetable v1.0.0

把同济大学课表固定在桌面上的 Windows 小组件 —— **首个正式版**，主线切到 WinUI 3（C#），解压即用。

## 下载

- `TJDesktopTimetable-v1.0.0-win-x64.zip`（自包含：**不需要**预装 .NET 或 Windows App Runtime）

解压到任意本地磁盘目录 → 双击 `Tjt.App.exe` → 首次启动会打开设置窗口的「导入课表」页。

## 这一版能做什么

**桌面挂件本体**

- 贴在桌面图标层（Owner = `SHELLDLL_DefView`）：被普通窗口正常覆盖，**按 Win+D 后依然可见**；不抢焦点。
- 无边框 + 自实现拖动/缩放：四边四角八块热区、缩放光标、最小尺寸、位置尺寸与显示器记忆。
- 四种窗口材质（Mica / Mica Alt / Acrylic / 实色）**运行时即时切换**，不重建窗口；深浅主题各自正确。
- 顶部条：「学期 · 第 N 周 · 今日 N 节」+ 刷新 + `⋯` 菜单（设置 / 导入课表 / 重新载入 / 恢复位置 / 贴桌面层 / 隐藏 / 退出）。
- 托盘常驻（`Shell_NotifyIcon`）：左键显示挂件，右键同一套菜单。

**课表数据**

- **粘贴一条浏览器请求**从 1 系统抓取个人课表（`findStudentTimetab` 新接口与 `getDataBk` 旧接口都支持），
  学期 id 自动从请求 URL 的 `calendarId` 取 → 「现在第几周」是准的；
- 本地 JSON 导入（粘贴或选文件），适配器自动探测；解析结果立即上桌面，**不需要手动挑教学班**；
- 失败时显示探测行（请求 / HTTP 状态 / 响应大小 / 数据识别）与适配器诊断，而不是笼统报错；
- 落盘 `%APPDATA%\TJDesktopTimetable\timetable.json`，可直接手工替换 / 备份。

## 质量

- C# **197** 个单测（模型 / 周次 / 冲突 / 布局 / 时间 / 适配器 / 视觉呈现 / 层级策略）+ TS 参考实现 **98** 个；
- 本机 29 项端到端验收脚本（`.tools/verify-import.ps1`）：载入顺序、导入落盘与读回、四个设置页构建、
  合成服务上的完整抓取链路（含报表格式与失败负例）、启动落在指定页；
- 真机实测：真实请求抓取 → 14 门 / 19 条；贴桌面层 Win+D 后 `visible=True / iconic=False`；四种材质像素可区分。

## 已知限制

- **不做自动登录**：1 系统 SSO 带短信增强，手动粘一条请求（一次即可）；登录态过期后需要重新复制。
- **研究生页的 `findSchoolTimetab2`** 分支按前端源码实现，未在真机实测（本科的 `findStudentTimetab` 已实测）。
- **内置学期表**只覆盖已知学期（当前 `122` / `124`）：更远的学期导入后课表正常，但顶部不显示「现在第几周」。
- **Acrylic** 需要透明窗口，观感可能弱于 Mica（窗口按非透明创建，材质是运行时切换的）。
- 设置里的「显示周末 / 周次过滤」尚未实现（控件当前为禁用）。
- 仅 Windows x64（Windows 10 2004+）。
