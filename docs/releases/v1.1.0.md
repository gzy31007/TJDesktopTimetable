# TJDesktopTimetable v1.1.0

内置登录窗口 + 「显示周末」开关；顺带修掉遮挡误拖、表头呼吸位、窗口图标三处问题。

## 下载

- `TJDesktopTimetable-v1.1.0-win-x64.zip`（自包含：**不需要**预装 .NET 或 Windows App Runtime）
- 解压到任意**本地磁盘**目录 → 双击 `Tjt.App.exe`（别放在 `\\wsl.localhost\...` 这类 UNC 路径下）

## 新增

**内置登录窗口（不用再手动抓包）**

- 应用自己的 WebView2 打开学校 1 系统，账号密码与短信验证都在**学校自己的页面上**完成；
  登录后点开「我的课表」，页面发出的课表接口响应被程序**旁路接住** → 走与粘贴请求**完全相同**的导入管线。
- 触发点两处：设置窗口「导入」页的「登录同济并获取课表」按钮；
  以及**启动时挂件上还没有真实课表**（只有内置样例 / 黄金数据）时自动打开。
- 登录态留在应用自己的 WebView2 profile（`%APPDATA%\TJDesktopTimetable\WebView2`），与系统浏览器隔离；
  窗口关闭了密码保存、自动填充与 DevTools。**不读**浏览器现有 cookie 库（那是绕过应用绑定加密）。
- 刻意不猜前端加密的 `studentCode`：页面自己发请求，前端换算法也照样抓得到。

**「显示周末」开关**

- 设置窗口「外观」页、挂件右上角 `⋯` 菜单、托盘菜单**三处同一个开关**，勾选状态永远一致。
- 关掉后课表只画周一到周五（7 列 → 5 列），周末的课**不占列**、列宽随之自适应变宽
  （实测同窗口宽下 172 → 241 DIP）；切换即时生效并落盘，不用重启。

## 修复

- **挂件被其他窗口遮挡时，光标扫过边缘不再误触发拖动 / 缩放**：起手先校验「指针归谁」
  （光标下窗口 → 根窗口 → 只接受自己 / 桌面壳 / owner 链），并在左键未按下时作废残留方向。
- **表头与顶部条之间补 6 DIP 呼吸位**，左侧时间标签改**居中**：缩窗口时不再出现"时间列与窗口边缘的空白越来越大"。
- **窗口图标显式设置**（`AppWindow.SetIcon`）：登录窗口的标题栏与任务栏不再回落到系统默认空白图标；
  窗口图标换成蓝色版，浅色标题栏上也看得清（托盘仍用白色版，画在深色任务栏上）。

## 变更

- **Electron + Vue 参考实现（`apps/desktop/` + `packages/core/`）及其 TS CI 已整体删除**，
  仓库只剩 `dotnet/` 一条线；黄金 fixture 迁到 `dotnet/fixtures/`（历史代码见 git 历史）。
- 登录入口收敛为上面两个触发点：挂件 `⋯` 菜单与托盘里的登录项已移除（换课表本来就要进「导入」页）。

## 质量

- 平台无关单测 **237** 项全绿（`TjtCore` + `Tjt.Widget`，Linux / CI 上就能跑）。
- 本机端到端验收脚本：`verify-weekend.ps1`（本版新增：7 列 / 5 列与外观页构建）、`verify-login.ps1`
  （本地合成服务跑完整捕获链路）、`verify-auto-login.ps1`、`verify-import.ps1`、`verify-icon.ps1` 等。
- 实机实测（黄金 fixture，14 门 / 19 条）：显示周末 → `blocks=19 days=7 colW=172`；
  隐藏周末 → `blocks=17 days=5 colW=241`。

## 已知限制

- 内置登录需要 **WebView2 运行时**（Windows 11 与较新的 Win10 已自带）。
- 研究生页的 `findSchoolTimetab2` 分支按前端源码实现，**未在真机实测**（本科 `findStudentTimetab` 已实测）。
- 内置学期表只覆盖已知学期（当前 `122` / `124`）：更远的学期课表正常，但顶部不显示「现在第几周」。
- **周次过滤（只看单周 / 双周）尚未实现**；Acrylic 需要透明窗口，观感可能弱于 Mica。
- 仅 Windows x64（Windows 10 2004+）。
