# TJDesktopTimetable v1.6.1

修复 Windows 在窗口较高时课表网格和课程色块不随高度拉伸、底部留下大块空白的问题。此版本是 v1.6.0 的补丁更新。

## 修复内容

- 保留文字的自然可读高度，把窗口内部剩余的纵向空间分配给节次行，网格、课程色块、节次标签和时间线一起更新。
- 窗口高度不足时不压行、不缩字，仍可滚动到末行；重新拉高后退出临时滚动，星期表头继续固定。
- 不自动改变窗口大小，不新增设置，也不改变已有课表和配置格式。Linux 沿用原布局，本次仅随统一版本重新构建。

## 下载与升级

- `TJDesktopTimetable-v1.6.1-setup.exe`：Windows 安装包，推荐使用，可覆盖安装旧版。
- `TJDesktopTimetable-v1.6.1-win-x64.zip`：Windows 绿色版，退出旧程序后解压到本地目录运行。
- `TJDesktopTimetable-v1.6.1-linux-x64.tar.gz`：Linux 自包含版，需要 X11 / XWayland、libICE / libSM 和中文字体。

Windows 包自包含，不需预装 .NET 或 Windows App Runtime。安装包未签名，SmartScreen 可能提示未知发布者。覆盖安装保留已有用户课表和设置。

v1.6.0 的更新检查可识别 v1.6.1。保持更新检查开启并重启应用，或在设置中手动检查，即可取得新版下载入口；这不是静默自动安装。网络不可用、关闭更新检查或跳过此版本时可能不显示提示。

## 验证与边界

修复已通过共享布局回归测试、Windows 编译和固定日期隔离冒烟；150% DPI 真实控件检查覆盖拉高填满、缩小滚至末行、固定表头和恢复退出滚动，用户已人工拖缩确认无问题。未扩为混合 DPI、多屏或拔屏矩阵，未新增 Linux 桌面运行时验收。
