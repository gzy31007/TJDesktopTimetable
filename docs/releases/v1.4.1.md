# TJDesktopTimetable v1.4.1

**v1.4.0 线的第一个正式版**（`v1.4.0-beta.1` 的预发布内容 + 本次国内网络修复）。

相对上一个正式版 v1.3.1 的主要变化：**上海交大「学在交大」课表**支持、**Windows 安装包**（`setup.exe`）、
首次启动不再替你选学校。本次新增 **gh-proxy.org 镜像兜底** —— 国内直连 GitHub 不通时，
新版本检查与下载链接都能用。

## 下载

- `TJDesktopTimetable-v1.4.1-setup.exe` · **Windows 安装包（推荐，约 59 MB）**
  → 双击安装 → 装到 `Program Files`；向导可勾选开始菜单 / 桌面快捷方式 / 开机自启 / 装完启动
- `TJDesktopTimetable-v1.4.1-win-x64.zip` · Windows 绿色版（自包含，**不需要**预装 .NET 或 Windows App Runtime）
  → 解压到任意**本地磁盘**目录 → 双击 `Tjt.App.exe`
- `TJDesktopTimetable-v1.4.1-linux-x64.tar.gz` · Linux（自包含单文件）
  → `tar -xzf ...` → 运行解压目录里的 `Tjt.Linux`

三份都是自包含的。**目前没有代码签名**，Windows 首次运行/安装时 SmartScreen 会提示"未知发布者"，
点「更多信息 → 仍要运行」即可。

## 新增：gh-proxy.org 镜像兜底（国内网络）

- **新版本检查**：先直连 `api.github.com`（超时 6 秒），直连拿不到响应就经 `https://gh-proxy.org/`
  镜像重试一次（超时 20 秒）。日志里会写清这一轮走的是「直连」还是「镜像」。
- **「发现新版本」的下载链接直接指向镜像**：`https://gh-proxy.org/https://github.com/.../releases/download/...`
  —— 国内点开就能下，不必再自己找加速。没匹配到本平台资产时退回 Release 页面，同样走镜像。
- 只对镜像**确实支持**的地址加前缀：`api.github.com` / `raw.githubusercontent.com` / `codeload.github.com`，
  以及 `github.com` 下带 `/releases/` 的路径（仓库主页不加 —— 镜像取不到，会 404）。
- 不想联网照旧：设置「常规」页关掉「检查新版本」即可，应用不会再发任何请求。

## 相对 v1.3.1 的主要变化（v1.4.0 线）

### 上海交通大学「学在交大」课表

- 数据源 `GET /app/stu/lesson/listBySemester`（整学期，带周次文本）+ `/app/stu/school/semester/calendar`（教务日历）。
- ⚠️ 课表页默认那条按周接口（`listByWeek`）**不带周次信息**，粘它也不会照抄：只取其中的 `year` / `semester`
  与 Cookie，改用登录态取整学期课表。粘哪条都行。
- 登录：设置「导入」页选「上海交通大学」→「登录并获取课表」，在应用自己的 WebView2 窗口里走 jAccount。
- 开学日取**第 1 周周一**；单双周在周次区间**展开之后**过滤；同一天同一教学班**相邻节次并成一块**。

### Windows 安装包（Inno Setup）

- 装到 `Program Files`，向导四个勾选；**卸载保留** `%APPDATA%\TJDesktopTimetable\`（完成页会打印路径）。
- 覆盖安装时挂件在运行会先问一句再关掉它；机器上没有 WebView2 只提示、不阻止。

### 首次启动与导入页

- 首次启动**不再**自动弹同济登录窗口（交大用户会被塞进同济登录页）——改显示一张**虚构的示例课表**
  并打开设置「导入课表」页，由你自己选学校。
- 运行时只认"你导入的"或"虚构示例"：发布包里**不含任何真实课表数据**。
- 导入页学校改成下拉框 + 一个「登录并获取课表」按钮；修了设置窗口缩小时说明文字横溢的布局 bug。

## 质量

- 平台无关单测 **320** 项全绿（v1.3.1 是 270，v1.4.0-beta.1 是 307）。
- Windows 与 Linux 两条线编译 **0 警告 0 错误**（`TreatWarningsAsErrors=true`）。
- 新版本检查验收 `.tools/verify-update-check.ps1` **8/8**：新增"直连失败 → 镜像兜底"一例
  （死端口直连 + 本地假镜像 → 镜像确实被请求、结论 `UpdateAvailable`、日志里的下载链接带镜像前缀）。
- 镜像连通性真机实测：API JSON / Release 资产 / Release 页 / raw 文件均返回 200。

## 已知限制

- **没有代码签名**：SmartScreen 会拦一次，README 里写明了怎么继续。
- 镜像 `gh-proxy.org` 是第三方服务（会 301 到 `gh-proxy.com`）：只用于版本查询与下载，**不上传任何本机数据**；
  直连可用时不会走它。
- 其余与 v1.3.1 相同：内置学期表只覆盖已知学期；周次过滤（只看单周 / 双周）尚未接 UI；
  Linux 版贴桌面层只在 KWin 上实测过，其他 WM 请用窗口规则兜底。
