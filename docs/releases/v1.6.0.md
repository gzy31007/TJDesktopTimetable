# TJDesktopTimetable v1.6.0

Windows 调整课表内容布局与窗口尺寸恢复，并固定滚动课表的星期表头。Windows 与 Linux 同版发布；本次新行为仅在 Windows 启用，Linux 保留原布局。

## 下载

- `TJDesktopTimetable-v1.6.0-setup.exe`：Windows 安装包，推荐使用。
- `TJDesktopTimetable-v1.6.0-win-x64.zip`：Windows 绿色版，解压到本地磁盘后运行 `Tjt.App.exe`。
- `TJDesktopTimetable-v1.6.0-linux-x64.tar.gz`：Linux 自包含版，解压后运行 `Tjt.Linux`。需要 X11 / XWayland、libICE / libSM 和中文字体。

Windows 两种包均自包含，不需要预装 .NET 或 Windows App Runtime。安装包未签名，SmartScreen 可能提示未知发布者。

## Windows：内容布局与临时滚动

- 按课名、教室、周次三行文字的实际高度分配非等高节次。单节课程可撑高对应行，跨节课程由覆盖行共同承担高度；空教室仍保留中间一行。
- 空间足够时整表纵向可见；窗口较矮时临时纵向滚动，不靠缩字或压行硬塞。加高窗口后自动退出纵向滚动，长文本仍可省略。
- 不按课表自动撑高窗口。同内容重绘及重新载入保留滚动位置；实际内容、周次视图或星期显示范围变化时归顶。

## Windows：固定星期表头与窗口尺寸

- 星期表头不随课表纵向滚动，横向位置仍与课程列保持一致。节次、时间、课程色块及当前时间线正常滚动，无新增开关。
- 保存物理像素外框与 DPI 比例，避免非整数 DPI 下反复重启造成尺寸取整漂移。恢复、拖动结束及工作区变化时将外框夹回可用工作区；适配后的尺寸作为下次恢复尺寸，不恢复屏幕变小前的旧目标。

## 验证与边界

- 发布前复跑平台无关测试，544 项全部通过。NuGet 安全数据缓存仍有 `NU1900` 访问权限警告，不影响测试结果。新版 Windows Release 构建无警告、无错误，固定日期 `--today 2026-09-21` 隔离冒烟 exit 0。
- 沿用已完成的单屏 100% / 125% / 150% / 200% 真实 WinUI 几何与滚动验证、150% 手动交互及工作区变化验证，以及固定表头的 25 步隔离会话。详细证据与工具退出状态见[验收记录](https://github.com/gzy31007/TJDesktopTimetable/blob/v1.6.0/docs/board-content-acceptance.md)。
- 混合 DPI 跨屏、显示器移除、100% / 125% / 200% 下的主观可读性及真实学校网络重新获取仍未验证，不把已有单屏证据扩大为这些场景已通过。
- Linux 随统一版本重新构建打包，本次没有接入内容布局、固定星期表头或 Windows 外框持久化逻辑，也未新增 Linux 桌面运行时验收。
