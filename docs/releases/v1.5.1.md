# TJDesktopTimetable v1.5.1

Windows 新增「下一次上课」单行摘要，并修正重新获取课表的保存与替换流程。Windows 与 Linux 同版发布，下面两项功能仅适用于 Windows，Linux 界面与导入流程未同步增加。

## 下载

- `TJDesktopTimetable-v1.5.1-setup.exe`：Windows 安装包，推荐使用。
- `TJDesktopTimetable-v1.5.1-win-x64.zip`：Windows 绿色版，解压到本地磁盘后运行 `Tjt.App.exe`。
- `TJDesktopTimetable-v1.5.1-linux-x64.tar.gz`：Linux 自包含版，解压后运行 `Tjt.Linux`。需要 X11 / XWayland、libICE / libSM 和中文字体。

Windows 两种包均自包含，不需要预装 .NET 或 Windows App Runtime。安装包未签名，SmartScreen 可能提示未知发布者。

## Windows：下一次上课

- 原顶栏下方增加固定单行摘要，显示尚未开始的最早一组上课安排。同刻开始的多条安排全部保留，正在上课的不算下一次。
- 「今」表示今天，「后」表示明天或更晚，不是倒计时。周次视图与隐藏周末不改变下一次上课的选择。
- 窄窗保持单行，辅助日期与时间先让位，再省略课名、教室。移入悬停浮层可滚动查看完整安排。
- 开课边界、跨日、重新显示、系统时间变化与睡眠恢复后重新核对。信息不足时不猜测下一次上课。

## Windows：重新获取与本地载入

- 「重新获取课表」向学校教务请求新数据；「重新载入课表」只读取本机已保存的数据，不联网。
- 新课表保存成功后才整份替换当前课表与画面，不与旧表合并。请求、解析、零课程或保存失败均保留旧表。
- 只有 HTTP 401/403 证据才提示登录失效，不再把普通网络或数据错误都归为需要重新登录。粘贴入口引导重新复制请求，内置登录入口引导关闭旧窗口后从导入页重新打开。
- 内置登录完成后更新导入页结果与当前课表摘要，页面重建可回放最近结果。

- 发布准备阶段重新运行平台无关测试，419 项通过，0 失败，0 跳过。NuGet 漏洞数据缓存出现 NU1900 访问权限警告，本次测试不代表依赖安全审计通过。
- 发布准备阶段重新执行 Windows 原生构建与固定日期冒烟，构建 0 警告、0 错误，冒烟退出码 0；固定 `--today 2026-09-21`，本周视图显示 14 个色块。
- 两项功能的既有 Windows 真机验收、独立审查与原始证据索引见[下一次上课验收记录](../next-class-summary-acceptance.md)及[重新获取验收记录](../refetch-transaction-acceptance.md)。前者包含真实 Modern Standby 睡眠恢复；后者包含真实 XAML / WebView2 与隔离文件锁验证，不使用学校账号或线上 SSO。
