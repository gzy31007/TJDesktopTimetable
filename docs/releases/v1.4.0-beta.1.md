# TJDesktopTimetable v1.4.0-beta.1

> **预发布（beta）**：加交大支持与 Windows 安装包，功能已本机验收但还没经过更广的使用检验。
> 它是 GitHub Release 里的 **Pre-release**，不会触发正式版用户的「新版本提示」。

## 下载

- `TJDesktopTimetable-v1.4.0-beta.1-setup.exe` · **Windows 安装包（推荐，约 59 MB）**
  → 双击安装 → 装到 `Program Files`；向导可勾选开始菜单 / 桌面快捷方式 / 开机自启 / 装完启动
- `TJDesktopTimetable-v1.4.0-beta.1-win-x64.zip` · Windows 绿色版（自包含，**不需要**预装 .NET 或 Windows App Runtime）
  → 解压到任意**本地磁盘**目录 → 双击 `Tjt.App.exe`
- `TJDesktopTimetable-v1.4.0-beta.1-linux-x64.tar.gz` · Linux（自包含单文件）
  → `tar -xzf ...` → 运行解压目录里的 `Tjt.Linux`

三份都是自包含的。**目前没有代码签名**，Windows 首次运行/安装时 SmartScreen 会提示"未知发布者"，
点「更多信息 → 仍要运行」即可。

## 新增：上海交通大学「学在交大」课表

除同济 1 系统外，现在也支持 `j.sjtu.edu.cn` 的课表。

- **数据源**：`GET /app/stu/lesson/listBySemester`（整学期，带 `time` 周次文本）+
  `GET /app/stu/school/semester/calendar`（逐日教务日历，决定开学日与总周数）。
- ⚠️ **课表页默认那条按周接口（`listByWeek`）不带周次信息**（`time` 全为 `null`），照它建挂件只会剩本周有课。
  所以粘贴它也不会照抄：程序只取其中的 `year` / `semester` 与 Cookie，改用登录态取整学期课表。
  粘 `listBySemester` 或 `listByWeek` 都行。
- **登录**：设置「导入」页选「上海交通大学」→「登录并获取课表」，在应用自己的 WebView2 窗口里走 jAccount。
  与同济一致：账号密码都在学校页面上输入，本应用不接触。
- 三个口径按交大课表页对齐：开学日取**第 1 周周一**（不是 `startDay`，那是报到周）；单双周在周次区间
  **展开之后**过滤（`5周,9周,13-15周` + `单周` → 5/9/13/15）；同一天同一教学班**相邻节次并成一块**。
- 请求只会打到 `j.sjtu.edu.cn` —— 粘错地址也不会把登录态发去别处。
- 已知：交大课表不显示教师姓名（接口只在课程详情里返回教师，挂件用不到，所以没多发那次请求）。

## 新增：Windows 安装包

- Inno Setup 构建，装到 `Program Files`；向导四个勾选：开始菜单 / 桌面快捷方式 / **开机自启** / 装完启动。
- **卸载保留你的数据**：`%APPDATA%\TJDesktopTimetable\`（课表 / 设置 / 登录信息）不动，完成页会打印路径。
- 安装包里的"开机自启"写的是 `HKCU\...\Run` 的 `TJDesktopTimetable`，与设置窗口那个开关**同一个值名**，
  两边不会打架。
- 覆盖安装时如果挂件正在运行，会先问一句再关掉它（否则文件被占用会装不上）。
- 机器上没有 WebView2 Runtime 时会在装完提示一次（只影响内置登录窗口，不影响粘贴请求导入）。

## 改进

- **首次启动不再替你选学校**：以前会直接弹出同济登录窗口（交大用户会被塞进同济登录页）。
  现在只显示一张**虚构的示例课表**，并打开设置窗口「导入课表」页，由你自己选学校。
- **内置示例课表换成虚构数据**：以前没导入过课表时显示的是 `dotnet/fixtures/` 里的**真实抓包**
  （脱敏，但确实是某人的真课表）。现在运行时只认"你导入的"或"虚构示例"，
  发布包里也**不再包含任何真实课表数据**。
- **导入页**：学校改成下拉框 + 一个「登录并获取课表」按钮（原来一校一个按钮）；
  复制请求的指引改为 **Copy as PowerShell**（`Copy as cURL` 仍支持）。
  修了一个布局 bug：设置窗口缩小时那段说明文字不会折行、会横着溢出。
- **「发现新版本」优先给安装包**：Release 同时挂 `-setup.exe` 与 `-win-x64.zip` 时，
  提示里的下载链接指向安装包；老 Release（只有 zip）仍按 zip 走。

## 质量

  URL 改写 / 探测等用例，以及"安装包优先"的资产匹配用例。

- 安装包 `.tools/verify-installer.ps1` **21/21**：安装 / 启动 / 覆盖升级 / **运行中安装** /
  卸载，并断言 `%APPDATA%` 数据 hash 前后不变。
- 交大的内置登录窗口由作者用真账号手工确认可用；抓取链路已自动化覆盖。

## 已知限制

- **没有代码签名**：SmartScreen 会拦一次，README 里写明了怎么继续。
- **"没有 WebView2 Runtime"这条分支没在真机验过**（开发机装了 Edge）—— 代码路径是查 EdgeUpdate 注册表后弹提示，
  需要干净虚拟机才能复现。
- 安装包向导界面是英文（Inno 自带语言文件）；应用名、快捷方式与所有应用内文案都是中文。
- 其余与 v1.3.1 相同：内置学期表只覆盖已知学期；周次过滤（只看单周 / 双周）尚未接 UI；
  Linux 版贴桌面层只在 KWin 上实测过，其他 WM 请用窗口规则兜底。
