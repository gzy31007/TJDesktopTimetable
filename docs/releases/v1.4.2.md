# TJDesktopTimetable v1.4.2

**查到新版本会弹系统通知**，点它直接打开设置「关于」页下载。国内网络那套（镜像兜底）与 v1.4.1 相同。

## 下载

- `TJDesktopTimetable-v1.4.2-setup.exe` · **Windows 安装包（推荐）**
  → 双击安装 → 装到 `Program Files`；向导可勾选开始菜单 / 桌面快捷方式 / 开机自启 / 装完启动
- `TJDesktopTimetable-v1.4.2-win-x64.zip` · Windows 绿色版（自包含，**不需要**预装 .NET 或 Windows App Runtime）
  → 解压到任意**本地磁盘**目录 → 双击 `Tjt.App.exe`
- `TJDesktopTimetable-v1.4.2-linux-x64.tar.gz` · Linux（自包含单文件）
  → `tar -xzf ...` → 运行解压目录里的 `Tjt.Linux`

**没有代码签名**：Windows 首次运行/安装时 SmartScreen 会提示"未知发布者"，点「更多信息 → 仍要运行」即可。

## 新增：新版本系统通知

- 启动后查到新版本时，除了原来的托盘菜单项 / 设置「关于」页提示，还会**弹一条 Windows 系统通知**
  （在通知中心里也能看到）。
- **点这条通知 → 直接打开设置窗口的「关于」页**（那一页有当前版本、更新状态、「下载」与「跳过此版本」按钮）。
  窗口已经开着就切到那一页，不会叠出第二个窗口。
- **同一个版本每次运行只提醒一次**：手动点「检查新版本」不会重复弹；点了「跳过此版本」就不再提醒它，
  但更高的版本照样会提醒。
- 实现走 `Shell_NotifyIcon` 的 `NIF_INFO`（Win10/11 上由系统按通知中心样式呈现），
  **不需要**注册 AUMID / COM 激活器 —— 绿色版解压即用也能弹。

## 保持 v1.4.1 的行为

- 版本查询先直连 `api.github.com`（6 秒），直连不通再经 `gh-proxy.org` 镜像重试；
  「下载」按钮给的链接也指向镜像，国内点开就能下。
- 不想联网：设置「常规」页关掉「检查新版本」即可，应用不会再发任何请求。

## 质量

- 平台无关单测 **323** 项全绿（v1.4.1 是 320，新增通知去重 / 文案长度用例）。
- 新版本通知验收 `.tools/verify-update-notify.ps1` **4/4**：A 有更新 → 真的弹出、B 已最新 → 不弹、
  C 响应非法 / D 网络失败 → 退出码 1。
- Windows 线编译 **0 警告 0 错误**（`TreatWarningsAsErrors=true`）。

## 已知限制

- 通知由系统托管：**开了「专注助手 / 勿扰」时不会显示**（与其它应用的通知一样），此时托盘菜单项与
  设置「关于」页仍会提示。
- 没有代码签名；`gh-proxy.org` 是第三方镜像（会 301 到 `gh-proxy.com`），只用于版本查询与下载，
  **不上传任何本机数据**。
