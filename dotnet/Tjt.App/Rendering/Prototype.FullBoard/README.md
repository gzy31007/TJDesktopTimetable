# 抛弃式原型 · 整表纵向可见（#19）

**用户已确认 C 的排版和最小高度推导规则；不是生产实现或 WinUI 验收结果。** 本目录只在 `prototype/19-full-board` 分支归档，不合入 main。

问题：保留顶部信息、下一次上课摘要、星期头与中间空节次时，什么样的排版、行高、字号及最小高度可以接受？

## 运行

从仓库根目录执行：

```sh
python3 dotnet/Tjt.App/Rendering/Prototype.FullBoard/serve.py
```

浏览器打开 <http://127.0.0.1:8191/?variant=A>。单命令启动，无依赖下载；服务只绑定 loopback，仅暴露本目录。`Ctrl+C` 停止。HTML 也可直接打开，不依赖服务端或外部资源。

原生 WinUI 没有可复用网页路由，因此在渲染层旁建立独立静态比较页，而不是修改应用窗口。A/B/C 在**同一页面**切换；URL 保存比较条件，刷新后可重现。底部左右箭头与键盘左右键循环切换；输入控件聚焦时不劫持方向键。切换条只在文件模式或 loopback 主机显示，整个目录均不得进入产品。

## 三个候选

- **A 等高压缩**：节次等高、三行文字；空间变小时缩小色块文字，课程跨度不同可能产生不同字号。
- **B 字号优先**：节次等高、课名一行，教室和周次并列一行；不足时增加预览高度而非进一步缩字。横向省略可能更早发生。
- **C 内容分配**：三行文字；根据跨节文字所需高度给有课节次留空间，整周空节次保留候选下限，剩余空间按权重分配。行高不等，中间节次不折叠。

B/C 的“保字号”指保留同块宽的候选字号；窄并排块仍保留宽度分档，小于输入字号时页面提示。所有方案保留课名、教室、周次与悬停详情；不尝试完整展开长名称。

可切换短跨度（1–4）、完整跨度（1–11）、长课名/单节课/三块并排场景，全部是虚构安排。只演示固定第 3 周、周一至周日的可见集合，不重新实现周次过滤、时间线、导入或设置。斜纹仅标识整周空节次，不是新增产品样式决定。

## 高度和读数

原型基线来自 `c47d9fe` 的 `Tjt.Widget/BoardVisual.cs`、`Tjt.Widget/NextClassSummary.cs`、`TjtCore/Layout.cs` 及 Windows 渲染器，只读取机制与尺寸；没有引用 DeskBox 的实现或资源。

固定预算：顶栏 34 + 摘要 30 + 画布顶部 6 + 星期头 28 + 底留白 6 = 104。候选最小高度 = 104 + 各节次候选下限之和。A 为等高下限；B 为两行文字所需的等高下限；C 为各节次文字需求与候选下限的较大值。控件中的 34、12、1080×600 等均为**未获认可的比较起点**。文字所需高度是浏览器行框的粗略预算，不是新的生产阈值。

如果请求高度低于当前候选下限总和，页面明确显示增加后的实际高度；此行为只为展示所需空间，**不决定**工作区不足、旧尺寸恢复或切换范围时的产品契约。极小行高下文字溢出会标记，不能当作可用候选。

页面展示请求/实际客户区尺寸、所有行的高度与位置、色块字号与省略状态、固定高度预算、DPR 和浏览器视口。页面允许滚动，挂件内部没有滚动；预览不自动缩放到页面宽度。悬停色块查看完整信息，完整状态也在页面下方。

浏览器保持 100%；CSS px 只是逻辑 DIP 的比较近似，DPR 可能混合系统缩放与浏览器缩放，不能用来反推出 Windows DPI。HTML 字体度量、材质、窗口外框均不等价于 WinUI，不能凭截图宣称真机可读。现行布局参考只是静态估算，不是现行应用复刻。
